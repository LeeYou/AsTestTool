# AsTestTool - 跨平台设备测试工具

## 项目概述

AsTestTool是一个跨平台的设备测试工具，用于测试身份证阅读器、摄像头/高拍仪和外接手写屏三种设备。该工具基于C++开发，使用ImGui作为GUI框架，支持Windows和Linux平台。

## 功能特性

### 已实现功能
- ✅ **跨平台架构**: 支持Windows和Linux平台
- ✅ **设备抽象层**: 统一的设备接口设计
- ✅ **插件化设计**: 支持不同厂家的设备驱动
- ✅ **日志系统**: 完整的日志记录和错误处理
- ✅ **配置管理**: 灵活的配置文件系统
- ✅ **基础框架**: 应用程序核心框架

### 设备支持
1. **身份证阅读器**
   - 支持通过DLL/SO调用厂家驱动
   - 可扩展的适配器模式
   - 支持多种阅读器类型

2. **摄像头/高拍仪**
   - Windows: DirectShow支持
   - Linux: V4L2支持
   - 实时预览功能
   - 分辨率设置

3. **外接手写屏**
   - 全屏手写窗口
   - 手写轨迹捕获
   - 支持多种手写屏设备

## 技术栈

- **编程语言**: C++17
- **构建系统**: CMake 3.16+
- **GUI框架**: ImGui 1.92.2
- **图形后端**: OpenGL 3.3+
- **平台支持**: Windows (DirectShow), Linux (V4L2)
- **依赖管理**: CMake FetchContent

## 构建说明

### 环境要求
- CMake 3.16+
- C++17兼容的编译器
- OpenGL 3.3+

### Windows构建
```bash
mkdir build
cd build
cmake ..
cmake --build . --config Debug
```

### Linux构建
```bash
mkdir build
cd build
cmake ..
make
```

## 运行说明

### Windows
```bash
cd build
.\AsTestTool.exe
```

### Linux
```bash
cd build
./AsTestTool
```
